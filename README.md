# Meridian

A dashboard for an Android phone, bonded to Termux. Readings come from the device, commands
run in Termux on that phone, there is no account and no server.

This repository now holds two complete builds side by side so you can choose later:

| Folder        | What it is                                                                  |
|---------------|-----------------------------------------------------------------------------|
| `original/`   | The shipped 1.8.6 source, extracted verbatim from `meridian-source.zip`.    |
| `clone/`      | The enhanced 2.0.0 clone: hardened bridge, Gradle project, new UI, licence-key paywall with trial. |
| `AUDIT.md`    | The full A-to-Z audit and roadmap: what was wrong, how it was fixed, what to build next, and how to make money with it. |

Start with `AUDIT.md`, then `clone/README.md` for build and payment setup.
