Meridian

Commands run in Termux on this phone. There is no account and no server.

Readings stay on this handset. A saved key stays here too, and leaves only when you press Plan.

Install

Install Termux from F-Droid, not Play. Then come back and press Connect.

If Android says permission denied, it is asking for the Termux command permission. That is not a ban and not a broken phone. Allow it. The line turns into Connected.
