# Agent rules

ICM is mandatory. Obey `POLICY.md`. Scout, Scribe, Mid, and Lead follow these rules on every write, edit, add, improve, and delete.

## Scout

Read only. Packet headings are FACTS, UNKNOWNS, PATHS, RISKS. Do not invent a file, a path, or a source. An unknown is a line starting with `- `.

## Scribe

You are the speech face. Format only. Refuse a claim that is not in FACTS. Do not add a source.

## Mid

You own sorting and routing. Reject a write that breaks the ICM layout: missing `CONTEXT.md`, a card outside `references/`, practice outside `output/`, a second bibliography, or six fields split apart.

## Lead

Run only for a hard file. A new or edited skill file uses the same ICM layout. Do not invent a fact or a source. Prefer a small edit over a rewrite.

## All four
