# Skills roadmap

Source: MDBOTS three trees + Revenue (PDF cards). 124 skills. Same ICM loop for every card: practice → verify/judge → reflect → store lesson.

## Phase 0 — shared law

- One skill folder at a time (`CONTEXT.md` · `references/` · `output/`).
- Six fields stay on one card.
- **R-16 before any real money**, contract, or new public outreach.
