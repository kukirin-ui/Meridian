# L-19 Code review and design critique — stage contract

Code Master · Tier 2 · Quality · Evidence B

## Inputs
- Skill card: `references/L-19.md` (six fields).
- Practice tasks: generated from the card's "How it is learned" protocol.
- Prior lessons for this skill: `output/`.
- Sources: the tree's `bibliography.md`.

## Process
1. Practice: run tasks from the card's learning protocol.
2. Verify: apply a checker (tests, an executor, a type checker, a proof kernel or a source file). Unchecked output is a draft.
3. Reflect: write what failed and why.
4. Store lesson: short lesson file into `output/`; into `references/` only after verification.

## Outputs
- Practice results and logged lessons in `output/`.
- Pass condition: the card's "Proof of mastery".
