# L-03 Surgical editing

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 0 · Ground

## Why it exists
Edits fail through collateral damage. The smallest change that passes the check protects everything that already works.

## How it is made
Read, state the hypothesis, make the smallest change (patch or diff, not a whole-file rewrite), re-run the check, review the diff line by line. The editing interface itself (viewer, editor, linter feedback) measurably changes success.

## What you can change
Edit granularity, diff format, test gate, maximum files per change.

## How it is learned
Modes M3 M5. Work through real issues; read many diffs before writing any; use tests as reward; add each failure pattern as a rule.

## Proof of mastery
The patch passes tests and the diff touches only intended lines.
