# L-15 Specification to tests

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 2 · Quality

## Why it exists
Tests turn intent into a checker the agent can run repeatedly.

## How it is made
Unit, integration and end-to-end tests, test-first design, property-based testing that checks general rules on generated inputs, and mutation checks that test the tests.

## What you can change
Test pyramid balance, generator strength, coverage target, flakiness policy.

## How it is learned
Modes M3 M5. Write tests for existing code, then break the code deliberately to see if the tests catch it.

## Proof of mastery
The suite fails on seeded bugs and passes on correct code.
