# L-25 Mobile and Android development

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 3 · Specialisations

## Why it exists
Phones are the most widespread computers, with strict lifecycle, permission and battery rules.

## How it is made
App components and lifecycle, Kotlin or Java, permissions, background work limits, storage, packaging and signing; integration with Termux and its API for automation.

## What you can change
Native versus cross-platform, background strategy, permission scope.

## How it is learned
Modes M5 M6. Build a small app and a Termux-driven automation; test on a real device.

## Proof of mastery
Installs, survives lifecycle changes and background limits, and requests only needed permissions.
