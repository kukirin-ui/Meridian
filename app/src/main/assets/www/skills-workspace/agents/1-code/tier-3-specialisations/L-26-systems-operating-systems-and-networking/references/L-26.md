# L-26 Systems, operating systems and networking

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 3 · Specialisations

## Why it exists
Everything runs on processes, memory, files and sockets; understanding them explains many mysterious bugs.

## How it is made
Processes and threads, virtual memory, file systems, system calls, TCP/IP, sockets and event loops; build small servers and tools from the ground up.

## What you can change
Blocking versus non-blocking I/O, protocol design, buffer sizes.

## How it is learned
Modes M5 M6. Write a small shell, a file tool and a network server, then trace their system calls.

## Proof of mastery
Working tools whose resource use and failure behaviour are explained from first principles.
