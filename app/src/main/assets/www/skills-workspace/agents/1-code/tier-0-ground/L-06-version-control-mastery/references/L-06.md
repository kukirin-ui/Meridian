# L-06 Version control mastery

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 0 · Ground

## Why it exists
History is the safety net for every other skill: it makes change reversible and explainable.

## How it is made
Small commits with clear messages, branches, rebase and merge, conflict resolution, bisect to find the commit that broke something, reflog to recover lost work.

## What you can change
Branching model, commit size, rebase versus merge, signing and review rules.

## How it is learned
Modes M5 M6. Recover from seeded disasters (lost commit, bad merge, wrong force-push) in a sandbox repository.

## Proof of mastery
Five seeded disasters recovered without data loss and with a clean history.
