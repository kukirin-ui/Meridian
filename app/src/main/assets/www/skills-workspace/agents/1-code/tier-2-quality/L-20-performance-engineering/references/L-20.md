# L-20 Performance engineering

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 2 · Quality

## Why it exists
Speed and memory use decide cost and user experience, and guesses about bottlenecks are usually wrong.

## How it is made
Measure first, profile (flame graphs), fix algorithmic problems before micro-optimisations, mind memory layout and I/O, re-measure. Premature optimisation is a known trap.

## What you can change
Target metric, profiler, caching strategy, parallelism.

## How it is learned
Modes M5 M6. Profile slow programs, predict the bottleneck, then check the prediction.

## Proof of mastery
A measured improvement with no behaviour change, and the cause predicted correctly.
