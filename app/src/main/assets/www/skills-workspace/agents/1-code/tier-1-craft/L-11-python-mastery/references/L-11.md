Python is the default language for automation, data and AI work.

## How it is made
The data model, iterators and generators, context managers, typing, standard library, packaging, async I/O, and when to call native code for speed. Follow the style guide and type-check.

## What you can change
Type strictness, sync versus async, packaging layout, dependency policy.

## How it is learned
Modes M5 M6. Build a command-line tool, a library and an async service, each with tests, types and packaging.

## Proof of mastery
A package with tests and strict type checks that installs cleanly and passes review.
