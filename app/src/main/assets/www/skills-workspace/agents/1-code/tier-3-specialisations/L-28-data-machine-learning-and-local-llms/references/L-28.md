# L-28 Data, machine learning and local LLMs

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 3 · Specialisations

## Why it exists
Local models, fine-tuning and data pipelines let an agent run and adapt without depending on outside services.

## How it is made
Data cleaning and splits, training loops and evaluation, parameter-efficient fine-tuning, quantisation, and local inference. Evaluate on held-out data and never on training data.

## What you can change
Model size, quantisation level, fine-tuning method, evaluation set.

## How it is learned
Modes M2 M5 M6. Train a tiny model from scratch, fine-tune a small one, and run quantised inference on a phone-class machine.

## Proof of mastery
Held-out evaluation shows a measured gain, and the model runs within the stated memory limit.
