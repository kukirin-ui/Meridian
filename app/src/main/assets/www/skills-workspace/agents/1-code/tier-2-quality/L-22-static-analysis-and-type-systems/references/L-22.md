# L-22 Static analysis and type systems

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 2 · Quality

## Why it exists
Machines can check large classes of errors before the program ever runs.

## How it is made
Linters, type checkers, sanitizers and shell analysers; designing types so wrong programs do not compile; reading and triaging tool output.

## What you can change
Strictness, which rules are enforced in CI, suppression policy.

## How it is learned
Modes M5. Turn on the strictest settings for old projects and fix the findings.

## Proof of mastery
Strict checks pass in CI and each suppression is justified.
