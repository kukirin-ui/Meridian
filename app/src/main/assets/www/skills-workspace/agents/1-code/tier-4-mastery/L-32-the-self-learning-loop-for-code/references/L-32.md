# L-32 The self-learning loop for code

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 4 · Mastery

## Why it exists
Fixed weights mean improvement must be engineered. Tests give code a real checker to learn from.

## How it is made
Choose tasks, attempt, run the tests, reflect on failures in words, store a lesson in a skill file, retry on new tasks. Unit tests are a reliable reward; self-correction without an outside check is not.

## What you can change
Task source, verifier, lesson storage, whether lessons train weights.

## How it is learned
Modes M3 M7. Run the loop on benchmark issues; retest old skills after each lesson.

## Proof of mastery
Measured gain on held-out issues, and no gain is claimed where no verifier exists.
