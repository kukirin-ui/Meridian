# L-17 Reading logs, traces and debuggers

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 2 · Quality

## Why it exists
Evidence from a running system is more reliable than reasoning about code alone.

## How it is made
Read stack traces from the bottom of the cause, use logs with context, set breakpoints and watchpoints, inspect memory, use browser developer tools and tracing for distributed calls.

## What you can change
Log level and format, sampling of traces, which tool for which layer.

## How it is learned
Modes M5 M6. Diagnose provided failure dumps and live problems from evidence only.

## Proof of mastery
Root cause identified from the evidence alone in a set of seeded failures.
