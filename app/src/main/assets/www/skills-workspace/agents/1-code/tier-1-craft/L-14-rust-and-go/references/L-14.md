# L-14 Rust and Go

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 1 · Craft

## Why it exists
Memory-safe systems languages and simple concurrent services are central in modern infrastructure.

## How it is made
Rust: ownership, borrowing, traits, error types. Go: goroutines, channels, interfaces, explicit errors. Learn both through small services and command-line tools.

## What you can change
Safety versus simplicity, concurrency model, error style.

## How it is learned
Modes M5 M6. Port one earlier project into each language and compare.

## Proof of mastery
Both ports pass the original tests and run without data races.
