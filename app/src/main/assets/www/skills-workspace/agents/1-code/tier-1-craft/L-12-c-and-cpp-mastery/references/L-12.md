# L-12 C and C++ mastery

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 1 · Craft

## Why it exists
Native code runs close to the machine and is unforgiving: memory errors become security holes.

## How it is made
Ownership and lifetimes (RAII), undefined behaviour, templates and the standard library, build systems, and debugging with a debugger and sanitizers.

## What you can change
Language standard, abstraction level, build flags, sanitizer coverage.

## How it is learned
Modes M5 M6. Write small systems with every sanitizer on; fix every report; read the core guidelines.

## Proof of mastery
Clean sanitizer runs, no undefined behaviour in review, and a reproducible build.
