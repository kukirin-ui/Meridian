# L-05 Shell and terminal fluency

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 0 · Ground

## Why it exists
The terminal is the control surface for almost everything an agent does on a machine, including Android through Termux.

## How it is made
Pipes, redirection, quoting, exit codes, globbing, process control and scripting. Safe scripts fail early, quote every variable and never run unreviewed downloaded code. Termux adds its own package manager, no root, and Android limits on background processes.

## What you can change
POSIX portability versus Bash features, strictness flags, logging, how much is scripted versus run by hand.

## How it is learned
Modes M5 M6. Write twenty small scripts, lint each, and run them on a clean environment; study the Termux wiki for platform limits.

## Proof of mastery
Scripts pass the linter, handle spaces and errors, and run unchanged on a fresh environment.
