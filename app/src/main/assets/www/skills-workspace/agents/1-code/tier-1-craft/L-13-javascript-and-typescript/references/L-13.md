# L-13 JavaScript and TypeScript

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 1 · Craft

## Why it exists
These languages run the web and much of the tooling around it.

## How it is made
The event loop and asynchronous behaviour, modules, the DOM, Node, and static types that catch errors before running.

## What you can change
Strictness of types, bundler choice, runtime (browser or server).

## How it is learned
Modes M5 M6. Build a small browser app and a server, both fully typed and tested.

## Proof of mastery
No type errors, correct async behaviour under test, and a working build.
