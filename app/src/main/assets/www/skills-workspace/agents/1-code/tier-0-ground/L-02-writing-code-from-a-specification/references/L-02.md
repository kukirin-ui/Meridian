# L-02 Writing code from a specification

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 0 · Ground

## Why it exists
Working code begins as a precise statement of what must be true. Fluent code that was never run is a draft.

## How it is made
Restate the requirement, list inputs, outputs and edge cases, write tests or examples first, implement the smallest correct version, run it, then clean up. Execution is the judge, since models produce plausible but wrong code.

## What you can change
Size of each step, test-first or test-after, language idioms, how much is generated at once.

## How it is learned
Modes M3 M5 M6. Solve benchmark problems against hidden tests and real small tasks; use test results as the reward; keep a catalogue of failure classes.

## Proof of mastery
High first-attempt pass rate on held-out problems, with tests that were written before the code.
