# G-09 Formats, compression and export pipelines

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 1 · Pixel and light

## Why it matters
The right file format decides quality, size, transparency and compatibility.

## How it works
Raster versus vector, lossy versus lossless, PNG, JPEG, WebP, SVG and PDF, colour profile embedding, sprite sheets and responsive image sets; pick by purpose and test the result.

## Ways to vary it
Format, quality setting, metadata stripping, size budget.

## How it is learned
Modes M5 M6. Export a set of assets for web, app and print, measure size and quality, and document the choices.

## Signs of mastery
Each export meets size and quality targets for its use.

**Failure mode:** one format for everything.
