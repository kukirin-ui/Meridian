# G-21 Interface visual design

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 4 · System and interface

## Why it matters
Screens must look good and work for every user and device.

## How it works
Layout and spacing systems, component states, responsive breakpoints, contrast and accessibility, platform conventions, and motion that explains change.

## Ways to vary it
Density, breakpoints, platform style, motion level.

## How it is learned
Modes M5 M6. Redesign five real screens, audit with accessibility checks and usability tests.

## Signs of mastery
Passes accessibility checks and tasks are completed faster in tests.

**Failure mode:** pretty but unusable.
