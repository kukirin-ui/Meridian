# G-20 Print and editorial layout

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 3 · Image and composition

## Why it matters
Print has fixed physical rules: bleed, margins, colour model and paper.

## How it works
Page grids, baseline grids, margins and bleeds, CMYK or spot colour, paged-media layout from code or a layout tool, pre-press checks and proofs.

## Ways to vary it
Grid, paper, colour model, binding.

## How it is learned
Modes M5 M6. Produce a multi-page document as a print-ready file and run pre-press checks.

## Signs of mastery
File passes pre-press checks with correct bleed and colour.

**Failure mode:** screen-only assumptions.
