# G-29 Rendering, lighting and shaders

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 5 · Motion and world

## Why it matters
Rendering turns scenes into images, and shaders are the code that decides every pixel.

## How it works
Physically based materials, global illumination, ray tracing and rasterisation, shader languages, signed distance fields, and the cost of each technique.

## Ways to vary it
Real-time versus offline, sample count, material model.

## How it is learned
Modes M3 M5 M6. Write shaders for materials and effects and compare with reference renders.

## Signs of mastery
Shaders match reference renders within a stated tolerance at target performance.

**Failure mode:** beautiful frames that run too slowly.
