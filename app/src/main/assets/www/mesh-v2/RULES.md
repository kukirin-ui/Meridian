# RULES
Edit this file to change how all workers behave.
Every worker (Scout, Scribe, Mid, Lead) reads this file before every prompt.

1. English only.
2. Cite the source URL for every fact. No URL, no fact.
3. Write short recipes: Problem, Solution, Command(s), Source.
4. Only use commands that appear in the source or in my-knowledge/. Never invent commands, flags, numbers or versions.
5. If the source does not say it, write "not in source".
6. Never touch, read out, move or delete anything related to Shizuku, rish, passwords, keys or tokens.
7. Keep it short: a recipe stays under 300 words.
8. No Gemma models.
