# G-34 Programmatic and automated graphics pipelines

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 6 · Machine imagination and the unknown

## Why it matters
Automation lets one design become thousands of correct assets.

## How it works
Generate graphics from data with code (SVG, canvas, Python imaging, command-line tools, scripted 3D); template systems; batch export; automated visual checks.

## Ways to vary it
Template design, data source, tolerance of visual tests.

## How it is learned
Modes M3 M5 M6. Build a pipeline that turns a data file into branded images and checks them automatically.

## Signs of mastery
A thousand assets render correctly from data with automated checks.

**Failure mode:** edge cases with overflowing text.
