# G-08 Vector construction

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 1 · Pixel and light

## Why it matters
Vector shapes scale without loss, so logos, icons and illustrations depend on them.

## How it works
Points, curves and paths; Bezier handles with few anchor points; boolean operations; strokes and expansion; clean, minimal path structure; SVG output.

## Ways to vary it
Anchor density, stroke versus outline, grid, optimisation level.

## How it is learned
Modes M5 M6. Redraw bitmap logos as clean vectors using the fewest points.

## Signs of mastery
Clean paths that scale and edit easily, with valid SVG.

**Failure mode:** traced paths with hundreds of needless points.
