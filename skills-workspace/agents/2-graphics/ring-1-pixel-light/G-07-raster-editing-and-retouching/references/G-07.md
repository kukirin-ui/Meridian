# G-07 Raster editing and retouching

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 1 · Pixel and light

## Why it matters
Most image work is editing existing pixels without destroying them.

## How it works
Layers, masks, adjustment layers, selections, healing, frequency separation, colour grading and non-destructive workflows; keep originals untouched.

## Ways to vary it
Tool (open-source or proprietary), destructiveness, how much to retouch.

## How it is learned
Modes M5 M6. Retouch a set of test images with a fully non-destructive file and compare with originals.

## Signs of mastery
Edits can be reversed or changed at any point and the result looks natural.

**Failure mode:** over-retouching.
