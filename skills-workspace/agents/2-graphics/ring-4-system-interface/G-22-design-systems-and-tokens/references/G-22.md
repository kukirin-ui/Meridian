# G-22 Design systems and tokens

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 4 · System and interface

## Why it matters
A system makes many designs consistent and fast to produce.

## How it works
Define tokens (colour, type, spacing, radius) once, build components from them, document usage rules, and generate code from the same source.

## Ways to vary it
Token set, component granularity, theming.

## How it is learned
Modes M5 M6. Create a small system and rebuild three different designs from it.

## Signs of mastery
Changing a token updates every design correctly.

**Failure mode:** a system so rigid nothing distinctive is possible.
