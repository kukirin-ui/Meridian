# G-11 Typography

**Evidence A: established** · Agent 2 · Graphics Master (imagination) · Ring 2 · Mark and type

## Why it matters
Most graphics contain text, and type controls tone, hierarchy and legibility.

## How it works
Letterforms, scale ratios, line length, spacing and leading, pairing, hierarchy, OpenType features and variable fonts, plus licensing and fallbacks for web.

## Ways to vary it
Typeface pairing, scale, measure, contrast of weights.

## How it is learned
Modes M5 M6. Set the same text in ten styles and test legibility and tone with readers.

## Signs of mastery
Text is comfortable to read at its target size and the hierarchy is obvious.

**Failure mode:** too many typefaces.
