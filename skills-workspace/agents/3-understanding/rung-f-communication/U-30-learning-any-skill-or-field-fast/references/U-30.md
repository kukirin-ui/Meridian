# U-30 Learning any skill or field fast

**Evidence B: benchmarked** · Agent 3 · Understanding Master (logic and imagination) · Rung F · Communication and learning

## Why it exists
The agent must master new fields on demand.

## How it is made (both halves)
**Logic half:** map the territory, learn the core ideas, move from textbook to papers, practise deliberately with feedback, test recall, and teach back.

**Intuition half:** finding the analogy that makes the field feel familiar. One-to-one tutoring and good practice raise results strongly.

## What you can change
Time per stage, practice difficulty, feedback source.

## How it is learned
Modes M5 M6. Learn a new field in 30 days with a plan, tests and a written explanation.

## Bridge test
Passes a competence test and writes an explanation an expert endorses.
