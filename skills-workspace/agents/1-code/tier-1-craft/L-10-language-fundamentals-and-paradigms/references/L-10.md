# L-10 Language fundamentals and paradigms

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 1 · Craft

## Why it exists
Understanding what languages share makes every new language fast to learn.

## How it is made
Scope, types, memory management, evaluation order, concurrency models, error handling, modules. Compare imperative, functional, object-oriented and logic styles on the same problem.

## What you can change
Static or dynamic typing, garbage collection or ownership, how errors are represented.

## How it is learned
Modes M5 M6. Solve the same five tasks in four languages and write a comparison of what each made easy or hard.

## Proof of mastery
Predicts the behaviour of unfamiliar code in a new language from concepts alone.
