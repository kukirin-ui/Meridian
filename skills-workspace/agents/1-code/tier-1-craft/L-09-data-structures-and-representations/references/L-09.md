# L-09 Data structures and representations

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 1 · Craft

## Why it exists
How data is laid out decides speed, memory and bugs.

## How it is made
Arrays, hash maps, trees, heaps, graphs, tries and probabilistic structures; choose by access pattern and memory layout; keep representations that make illegal states impossible.

## What you can change
Cache behaviour, mutability, serialisation format, index design.

## How it is learned
Modes M5. Implement each structure from scratch, then benchmark against the standard library.

## Proof of mastery
Implementations pass property tests and match library performance within a stated factor.
