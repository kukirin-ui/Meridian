# L-08 Algorithm design and analysis

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 1 · Craft

## Why it exists
Choosing the right algorithm often matters more than any optimisation.

## How it is made
State the problem and invariants, pick a paradigm (greedy, divide and conquer, dynamic programming, graph search), prove or test correctness, analyse time and space. Stress-test against a brute-force solution on small inputs.

## What you can change
Exact versus approximate, memory versus time, worst case versus average case.

## How it is learned
Modes M3 M5. Solve graded problem sets; always compare with brute force; use passing tests as reward.

## Proof of mastery
Correct and within complexity limits on adversarial stress tests.
