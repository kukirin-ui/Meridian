# L-18 Refactoring and legacy code

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 2 · Quality

## Why it exists
Old code is where most work happens, and rewrites usually cost more than expected.

## How it is made
Add characterisation tests that pin current behaviour, make small behaviour-preserving steps from a catalogue, replace parts gradually, and keep the system working throughout.

## What you can change
Step size, how much to rewrite, module boundaries.

## How it is learned
Modes M5 M6. Take a messy open-source module, pin its behaviour, and refactor in steps with tests green.

## Proof of mastery
Behaviour is unchanged by tests and the structure measurably improves.
