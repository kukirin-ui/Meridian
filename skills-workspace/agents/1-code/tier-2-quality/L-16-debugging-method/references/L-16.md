# L-16 Debugging method

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 2 · Quality

## Why it exists
Most engineering time is spent finding why code does not do what was intended.

## How it is made
Reproduce, minimise the failing case, form a hypothesis, test it (bisect or print or debugger), fix the root cause, add a regression test. Treat it as the scientific method with an executable experiment.

## What you can change
Order of hypotheses, tooling, how small the minimal case must be.

## How it is learned
Modes M3 M5 M6. Debug seeded bugs and real issues; keep a log of cause, signal and fix.

## Proof of mastery
Seeded bugs are found by method rather than luck, each with a regression test.
