# L-29 DevOps, CI/CD and observability

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 3 · Specialisations

## Why it exists
Reliable delivery needs automation and visibility.

## How it is made
Continuous integration and deployment, containers, infrastructure as code, metrics, logs and traces, alerting, incident response and postmortems.

## What you can change
Pipeline stages, alert thresholds, rollback method.

## How it is learned
Modes M5 M6. Build a pipeline that tests, builds and deploys a small service, then break it and diagnose from telemetry.

## Proof of mastery
A change reaches production only through green checks, and a seeded fault is found from telemetry.
