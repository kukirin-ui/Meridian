# L-30 Compilers, interpreters and domain languages

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 3 · Specialisations

## Why it exists
Building a language shows how all code is understood by machines and lets you create the right notation for a problem.

## How it is made
Lexing, parsing into trees, semantic checks, intermediate forms, interpreters and virtual machines; design a small language with a grammar and tests first.

## What you can change
Syntax weight, typing, interpreter versus compiler.

## How it is learned
Modes M5 M6. Build an interpreter and a small domain language from a textbook.

## Proof of mastery
The interpreter passes its conformance suite and a newcomer completes tasks in the small language.
