# L-27 Databases and distributed systems

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 3 · Specialisations

## Why it exists
Data outlives code, and distribution adds partial failure.

## How it is made
Relational modelling, indexes, transactions and isolation, query plans; replication, consensus, ordering of events, and the trade-offs of consistency and availability.

## What you can change
Isolation level, schema design, replication mode.

## How it is learned
Modes M5 M6. Design a schema, load realistic data, tune queries, and simulate node failures.

## Proof of mastery
Queries use intended indexes, transactions are correct under concurrency, and failure behaviour is predicted.
