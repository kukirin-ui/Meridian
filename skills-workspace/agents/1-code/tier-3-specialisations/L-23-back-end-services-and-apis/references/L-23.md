# L-23 Back-end services and APIs

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 3 · Specialisations

## Why it exists
Most software value is delivered through services that other programs call.

## How it is made
HTTP semantics, resource design, authentication, idempotency, rate limits, queues and background jobs, configuration and logging in the twelve-factor style.

## What you can change
API style, auth method, consistency of errors, versioning.

## How it is learned
Modes M5 M6. Build and test a small service with a documented API and failure handling.

## Proof of mastery
Passes contract tests including bad input, timeouts and repeated requests.
