# L-34 Specialist depth

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 4 · Mastery

## Why it exists
Breadth gets work started; depth in a niche earns trust and income.

## How it is made
Choose a niche, read the source of leading projects, reproduce key papers or benchmarks, contribute fixes upstream, and practise deliberately on the hardest sub-problems. Expertise needs a domain with stable regularities and feedback.

## What you can change
Niche choice, depth versus breadth, contribution target.

## How it is learned
Modes M5 M6. Pick a niche for 90 days; set reproducible milestones and review them.

## Proof of mastery
A reproduced result and an accepted upstream contribution in the niche.
