# L-33 Agentic coding and ICM workspaces

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 4 · Mastery

## Why it exists
Real tasks need plans, tools and memory over many steps, with a human in control.

## How it is made
Plan, call tools, observe, repair, stop at a budget. Jake Van Clief's ICM organises the agent's context as folders and plain-text stage contracts so the right files load at the right moment and humans can edit any step.

## What you can change
Number of stages, checkpoints, tool permissions, memory policy.

## How it is learned
Modes M5 M6. Build a coding workspace with stages for plan, implement, test and review; run it on real tasks.

## Proof of mastery
Tasks complete within the step budget, each stage output is editable, and no unapproved side effects occur.
