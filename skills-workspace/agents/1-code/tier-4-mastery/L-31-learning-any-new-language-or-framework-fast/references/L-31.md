# L-31 Learning any new language or framework fast

**Evidence B: benchmarked** · Agent 1 · Code Master (logic) · Tier 4 · Mastery

## Why it exists
The required technology changes constantly. The skill is to become productive in anything quickly and correctly.

## How it is made
Map its concepts to ones already known, read the official tutorial and reference, set up the toolchain (build, test, package), learn idioms from the standard library and style guide, port a known small project, then read real code and get feedback from linters and tests.

## What you can change
Which known language is the anchor, size of the first project, depth of reading before coding.

## How it is learned
Modes M5 M6. Learn one new language per month this way; keep a note of the concept map and the traps found.

## Proof of mastery
A working, tested, idiomatic project in a new language within days, passing a style check.
