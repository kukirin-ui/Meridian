# L-07 Environments, dependencies and builds

**Evidence A: established** · Agent 1 · Code Master (logic) · Tier 0 · Ground

## Why it exists
Code that only runs on one machine is not finished. Reproducible builds make results trustworthy.

## How it is made
Isolated environments, pinned dependencies and lock files, one-command builds (make, CMake, npm, cargo), containers when needed, configuration through environment variables, no secrets in code.

## What you can change
Pinning strictness, container versus virtualenv, build system choice.

## How it is learned
Modes M5 M6. Take ten real projects, build each from the README on a clean environment, and record every missing step.

## Proof of mastery
A fresh machine builds and tests the project from the README in one command.
