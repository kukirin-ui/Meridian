# Meridian 1.8.6 (archived original)

This folder is the shipped 1.8.6 source, extracted verbatim from `meridian-source.zip`.

The live app in this repository is **2.0.0** at the repo root (`app/`). See `../README.md` and `../AUDIT.md`.

Readings come from the device. Commands run in Termux on that phone. There is no account and no server.

Layout here matches the 1.8.6 zip: `AndroidManifest.xml`, `src/`, `assets/www/index.html`, and `res/`. MIT licence. The signing key is not included.
