# Meridian

A dashboard for an Android phone, bonded to Termux. Version 1.8.6.

Readings come from the device. Commands run in Termux on that phone. There is no account and no server.

This repository is the application source: `AndroidManifest.xml`, `src/`, `assets/www/index.html`, and `res/`. It is released under the MIT license. People may study it, share it, change it, and fork it.

The signing key is not included.
